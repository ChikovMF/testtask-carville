# Расчёт цен с НДС и без НДС

Решение тестового задания ([docs/TASK.md](docs/TASK.md)) на C#.

По рекомендованной цене с НДС и проценту НДС процедура находит пару цен с НДС и без НДС, для которых:

- обе цены содержат не более 2 знаков после запятой;
- `цена с НДС = цена без НДС × (1 + процент НДС / 100)` выполняется точно, без округлений;
- цена с НДС максимально близка к рекомендованной.

## Правила

- Процент НДС: целое число от 0 до 99.
- Цена с НДС: неотрицательное число, не больше 9 999 999 999 999.99.
- Если рекомендованная цена ровно посередине между двумя подходящими ценами, выбирается большая.

## Структура

| Проект | Назначение |
|---|---|
| `src/Carville.Pricing` | Библиотека с расчётом: `PriceCalculator.CalcPrices` и `PriceCalculator.TryCalcPrices` |
| `src/Carville.Pricing.Terminal` | Консольное приложение для проверки расчёта |
| `tests/Carville.Pricing.Tests` | Модульные тесты (xUnit) |

`CalcPrices` повторяет сигнатуру из задания и при недопустимой цене бросает `ValidationException`.
`TryCalcPrices` работает без исключений и возвращает причину ошибки.

## Запуск

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download).

Консольное приложение:

```
dotnet run --project src/Carville.Pricing.Terminal
```

Тесты:

```
dotnet test
```
